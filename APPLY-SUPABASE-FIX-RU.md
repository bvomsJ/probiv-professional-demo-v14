# PROBIV — исправление сохранения и закрытых тем

## Что исправлено в коде

- Тексты тем и сообщения больше не хранятся в публично читаемом `app_state` JSON.
- Темы вынесены в `public.forum_threads`; правило RLS возвращает гостям только открытые темы. Закрытые темы доступны только авторизованным профилям и администратору.
- Загрузка темы ждёт результат Supabase/RLS. Если проверить доступ не получилось, содержимое не показывается.
- `?preview=1`, старый `PROBIV_MEMBER` и прочие значения `localStorage` больше не открывают закрытую тему при включённом Supabase.
- Все изменения из админки (настройки сайта, страницы, разделы, темы и сообщения) сохраняются через RPC `admin_save_site_state`; сохранение сайта и списка тем выполняется одной транзакцией.
- Сохранения ставятся в очередь, чтобы быстрые последовательные изменения не терялись.
- Загрузка медиа использует Supabase Storage и таблицу `media`.

## ВАЖНО: сначала SQL, затем файлы сайта

1. Открой Supabase → **SQL Editor**.
2. Выполни целиком файл `supabase/002_media_storage.sql`.
3. После успешного выполнения выполни целиком `supabase/003_secure_topics_and_persistence.sql`.
4. Убедись, что оба скрипта завершились без ошибки. Второй скрипт переносит темы из старого `app_state` в `forum_threads` и удаляет ключ `threads` из публичного JSON.
5. Загрузи **все файлы из архива в корень существующего GitHub Pages репозитория**, с заменой старых файлов. Не загружай только отдельный `thread.html` или только JS — они должны обновиться вместе.
6. Не перезапускай старый `001_schema.sql`, если схема уже была применена. Не публикуй `.env`, service-role key или секретные ключи. `supabase-config.js` содержит только публичный publishable key.
7. Подожди завершения GitHub Pages deployment и сделай жёсткое обновление сайта: `Ctrl+F5`.

## Как проверить

1. Войди в админку как Supabase-пользователь с ролью `admin`.
2. Открой тему, переключи доступ на **«Вход / приглашение»**, нажми «Сохранить тему» и дождись сообщения об успешном сохранении в Supabase.
3. Открой приватное окно браузера без входа и вставь прямую ссылку на эту тему. Должно появиться сообщение, что тема не найдена; её текст и сообщения не должны загружаться.
4. В той же приватной сессии открой поиск/категорию — закрытая тема не должна отображаться после загрузки серверного состояния.
5. Войди обычным подтверждённым пользователем — закрытая тема должна быть доступна.
6. Измени текст в настройках сайта/правилах или заголовок открытой темы, перезагрузи страницу и проверь, что изменение осталось.
7. В админке загрузи изображение, обнови страницу и проверь, что медиа сохранилось.

## Если SQL не применился

Не выкладывай обновлённые файлы до успешного выполнения обоих SQL-файлов. Новая версия намеренно не использует локальный список тем как запасной источник при ошибке Supabase: это необходимо, чтобы закрытые тексты не раскрывались при сбое сети или политик доступа.
