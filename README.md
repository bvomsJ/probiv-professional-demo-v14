# PROBIV.CC — FINAL DEMO BUILD

Локальный синтетический макет классического форума. Все данные вымышлены.

## Состав

- `index.html` — главная (плотный форум: слева новые пользователи, центр — темы, справа — сервисные блоки).
- `category.html` — раздел с пагинацией и созданием темы.
- `thread.html` — тема и сообщения, реакции, медиа.
- `profile.html` — профиль (только для участников).
- `search.html` — поиск по темам, пользователям, разделам.
- `login.html`, `register.html`, `invite.html` — авторизация.
- `rules.html`, `help.html` — редактируемые страницы.
- `admin.html` — админ-панель со всеми редакторами и live-preview.
- `data.js` — демо-данные и инициализация `DEMO_DB` (localStorage `PROBIV_DEMO_DB`, версия `v9`).
- `site.js` — ядро: авторизация, доступ, рендер главной, медиа, реклама, drag-and-drop.
- `style.css` — стили.

## Удалено

Файлы `app.js` и `app(1).js` — остатки старой сборки, несовместимые с текущей моделью данных. Не подключать.
