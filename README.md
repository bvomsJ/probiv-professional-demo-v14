# PROBIV.CC — FINAL DEMO BUILD

Это локальный синтетический макет форума для демонстрации интерфейса.

## Что внутри

- Плотная главная страница в стиле классического форума: новые пользователи слева, список новых сообщений/тем по центру, сервисные блоки справа.
- Страницы форума: разделы, темы, сообщения, профили, поиск, правила, помощь.
- Локальная регистрация по приглашению.
- Локальный вход участника.
- Отдельная демонстрационная админ-панель с CRUD для разделов, тем, сообщений и пользователей.
- Медиатека PNG/JPG/WebP/GIF.
- Визуальный конструктор рекламных блоков с изменением позиции и размера в live-preview.
- Резервное копирование JSON: экспорт, импорт и сброс.
- Синтетические данные без реальных аккаунтов, операций и внешних сервисных функций.

## Демо-доступ

Администратор:
- Логин: `admin`
- Пароль: `DEMO-ADMIN-2026`

Приглашение:
- Код: `DEMO-2026`

Обычного пользователя можно выбрать через страницу входа по имени из демо-базы или создать нового участника через регистрацию.

## Как запустить

Самый простой способ — открыть `index.html`.

Для максимально корректной работы браузерного локального хранилища можно использовать любой локальный статический сервер.

## Где что менять

Главная → «Карта сайта» в админке показывает каждый блок отдельно.

Основные редакторы:
- «Главная → Шапка» — логотип, слоган, верхняя надпись, фон, футер.
- «Главная → Верхние баннеры» — тексты верхних рекламных блоков.
- «Главная → Статистика» — цифры статистики.
- «Главная → Горячие темы» — рекомендации.
- «Главная → Списки тем» — список «Новые сообщения».
- «Главная → Разделы» — названия/описания/счётчики разделов.
- «Главная → Правая колонка» — подписи сервисных блоков.
- «Главная → Нижние баннеры» — четыре медиа-слота.
- «Форум → Разделы» — полный CRUD разделов.
- «Форум → Темы» — полный CRUD тем и их параметров.
- «Форум → Сообщения» — просмотр сообщений и переход в редактор темы.
- «Медиа → Медиатека» — загрузка и назначение медиа.
- «Медиа → Рекламные блоки» — точная настройка размеров и расположения.
- «Люди и доступ → Пользователи» — пользователи и профили.
- «Люди и доступ → Приглашения» — коды доступа.
- «Система → Навигация» — управляемые пункты меню.
- «Система → Страницы» — правила и помощь.
- «Система → Резервная копия» — экспорт/импорт/reset.

## Локальное хранение

Рабочая база хранится в `localStorage` под ключом `PROBIV_DEMO_DB`.

Когда админ открывает live-preview, черновик хранится отдельно в `sessionStorage` и не должен менять рабочую базу до сохранения.

## Важное ограничение

Это frontend-демо. `localStorage`, демонстрационный логин и пароль не являются механизмом настоящей серверной безопасности.

Для production-версии необходимы серверная авторизация, база данных, RLS/серверные проверки и безопасное хранение секретов.
