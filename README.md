# PROBIV.CC — v7 DEMO / hardened interactive forum

Синтетический интерактивный макет. Не является реальным форумом и не содержит
реальных аккаунтов, персональных данных, финансовых операций или внешних сервисов.

## Исправления v7
- реакции 👍/👎 больше не накручиваются бесконечно: один локальный участник = одна реакция на сообщение;
- повторное нажатие снимает реакцию;
- переключение 👍 ↔ 👎 корректно переносит реакцию;
- автору сообщения корректируются синтетические счётчики;
- темы, горячие темы, последние сообщения, профили и разделы ведут на реальные локальные страницы;
- гостевой доступ к закрытой теме ведёт на страницу входа/приглашения;
- формы входа/регистрации/ответа/создания темы имеют рабочие демонстрационные сценарии;
- админка позволяет редактировать сайт, главную, разделы, темы, пользователей, доступ, приглашения и ссылки;
- добавлен редактор ссылок с понятными локальными назначениями;
- навигация использует настройки ссылок из админки;
- профили позволяют редактировать основные поля, награды, статус и синтетические показатели;
- проверены JS-файлы на синтаксические ошибки;
- проверены HTML-ссылки на отсутствующие страницы;
- фон `background.png` — предоставленный референс пользователя;
- DEMO-плашки и синтетическая маркировка сохранены.

## Демо
Код приглашения по умолчанию: `DEMO-2026`.

Изменения сохраняются только в localStorage текущего браузера.
Для чистого состояния очистите localStorage для страницы или откройте в новом профиле браузера.
