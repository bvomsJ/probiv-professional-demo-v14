# PROBIV.CC — FINAL DEMO FORUM UI

Финальная статическая демонстрационная сборка форума на синтетических данных.

## Что внутри

- Главная в плотной компоновке, ориентированной на предоставленный референс: левые «Новые пользователи», центральный список тем, правые виджеты, маленькие строки и цветные метки.
- Отдельные страницы разделов, тем, профилей, поиска, входа, регистрации, приглашения, правил и помощи.
- Админ-панель с сохранёнными CRUD-функциями и разбивкой редактора по конкретным блокам сайта.
- Медиатека, рекламные блоки, live preview, экспорт/импорт локальной JSON-базы и сброс демо-данных.
- Все данные локальные и синтетические; реального backend/auth/платежей в этой сборке нет.

## Доступ в демо

Админ: `admin` / `DEMO-ADMIN-2026`

Приглашение: `DEMO-2026`

## Проверка перед выдачей

Проверены синтаксис внешних и inline JavaScript, наличие внутренних файлов/ссылок, отсутствие дублирующихся HTML-ID, целостность синтетической базы (пользователи → темы → сообщения → разделы), а также ключевая логика доступа к профилям и закрытым темам.

Для обычного гостя переход на профиль ведёт на вход; параметр `preview=1` не открывает закрытые темы без административной сессии; несуществующие ID профиля, темы и раздела не подменяются случайной записью.

Сборка предназначена для локального/учебного демо. Перед реальным публичным размещением авторизацию, роли и хранение данных необходимо перенести на серверный backend с RLS/ACL.
